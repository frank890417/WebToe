WebToe is a node-based dataflow engine for real-time visuals that runs in the browser. You patch operators into a network, drive parameters with expressions, and watch the result cook every frame on WebGL2 or WebGPU. It also opens TouchDesigner projects.

The fastest way in is to [open the editor](/app/) and load an example from the toolbar. [Getting started](getting-started.md) covers the editor, running it locally, and working on the source.

These pages describe the code in [the repository](https://github.com/frank890417/WebToe) as of this build. Numbers that come from measurements say where they were measured.
